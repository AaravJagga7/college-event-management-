⚡ Neptune.ai Cloud Synchronization & Configuration
How to stream runs directly to app.neptune.ai or synchronize offline experiment sessions.

1. Sync Existing Offline Runs to Neptune.ai:

All 9 model runs from this training session are currently stored locally in .neptune/offline. To push them to your cloud dashboard, run:

export NEPTUNE_API_TOKEN="your_neptune_api_token"
export NEPTUNE_PROJECT="your_workspace/college-event-ml"

# Synchronize all local runs to cloud
neptune sync

2. Live Cloud Streaming Mode:

Whenever NEPTUNE_API_TOKEN is set in your environment, train_models_neptune.py automatically switches from offline mode to async cloud streaming mode:

python3 train_models_neptune.py
